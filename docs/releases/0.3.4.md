# BBReader 0.3.4

- 新增开机自启动：正常程序首次运行默认开启，可在“连接与设置 → 开机自启动”关闭。升级保留选择，系统外部禁用也不会反复被开启；下载后需运行程序一次才会登记。该设置与课件自动下载独立。
- 修复更新重复显示安装向导：安装版下载完成后点击“重启并安装”，静默升级并启动新版。新安装器识别旧客户端的升级标记，首次手动安装仍有目录选择向导；系统权限/签名提示由系统处理。
- 加快课程检查：去掉每段后的 30 秒空等，课件信息最多三份并发核对；使用阶段进度，目录发现时显示已读取页数，避免新增页面令进度倒退。实际耗时仍取决于学校网络和课程规模。
- 首次课件自动下载默认关闭，可按需开启；已保存的开关选择、勾选/全课程下载、原重试入口、命名与路径规则保持。

本版不包含桌面小组件。保留原课程、作业、下载、预览、新课件提醒、学校会话及索引格式，不清空已下载文件。没有新增用户运行依赖；Windows/macOS 使用原生启动项，Linux 使用用户级桌面自启动文件。

Windows 推荐下载 `BBReader-0.3.4-windows-x64-setup.exe`。安装版可通过应用内检查更新升级；便携版提供新版下载页。旧 0.3.1 用户先手动安装本 Fork。

验证记录见 docs/regression.md。实际跨版本覆盖安装和重启电脑后的自动启动仍需实机验收，模拟测试不等同于完成此项。未签名包仍可能显示系统提示。

58 项正式测试、Windows/macOS 桌面回归和三平台构建通过。[构建记录](https://github.com/siyou-622/BBReader/actions/runs/38535349040)。Windows 安装器及便携包通过 CI Defender 扫描（病毒库 `1.461.20.0`），发布资产摘要与扫描记录及 SHA256SUMS.txt 一致；报告随包提供。Windows 自启动原生接口已经临时项实测并清理。
