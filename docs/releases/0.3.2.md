# BBReader 0.3.2 桌面增强版

基于 [Carbene/BBReader](https://github.com/Carbene/BBReader) 的 0.3.1，保留原作历史、版权及 MIT 许可证。此版本由 [siyou-622/BBReader](https://github.com/siyou-622/BBReader) 发布。

## 下载与启动

- **Windows 64 位安装版（推荐）**：下载 `BBReader-0.3.2-windows-x64-setup.exe`，安装后从桌面快捷方式启动。无需安装 Node、Python 或通过外部浏览器访问。
- **Windows 64 位便携版**：下载 `BBReader-0.3.2-windows-x64-portable.exe`，直接运行。
- **Chrome 扩展**：下载 `BBReader-browser.zip`，解压后按 README 加载 `extension` 文件夹，原浏览器使用方式保留。

旧版本用户请先通过“应用 → 退出”完全退出旧程序，再运行新版。旧 0.3.1 需手动更新一次；安装版 0.3.2 已连接本 Fork 的更新源，后续更高版本可在“连接与设置 → 软件更新”中检查、下载和明确点击重启安装。便携版通过下载页替换程序。

## 本版改进

- 新增 Electron 桌面入口，复用原课程、作业日程、成绩、主题、自动检查、账号设置及导出逻辑。
- 按课程勾选课件批量下载，并支持下载当前课程全部课件；保留原自动下载、文件命名与归档路径。
- 显示下载进度、成功/失败及重试；处理同名、重复下载、网络中断和本地文件丢失。隐藏冗长路径，已下载文件可以定位文件夹。
- 相同课程选择也能保存；使用新的文档勾选桌面图标。
- 支持应用内预览、系统默认软件和指定阅读软件；“预览”不会直接改成下载，外部软件打开需先有本地文件。操作按钮横排，不显示上传时间。
- 检查后提供可点击的新增/更新统计，区分首次基线、后来发现与已有文件更新；缺失版本证据或检查中断时给出提示。
- 学校登录遇到白屏、代理、网络或证书错误时提供原因提示和重试；空网址不再误报已加载。
- 增加更新窗口，更新包来自本 Fork，显式下载/安装；有课件下载或检查任务时阻止安装中断。

## 验证与限制

49 项 Node 测试通过；重新打包的 Windows 程序通过下载/重试、PDF 预览、课程保存、导出、更新窗口、学校错误提示与重启持久化回归。原浏览器 ZIP 构建通过。真实学校登录页诊断成功到达统一认证页面，但未替用户输入账号登录。

Windows 包未配置代码签名。macOS/Linux 桌面构建配置已提供，尚未完成对应实机验收，因此本次只提供 Windows 桌面包及通用浏览器扩展。更新流程测试使用模拟安装调用，尚未执行真实跨版本覆盖安装。详见 [回归记录](https://github.com/siyou-622/BBReader/blob/main/docs/regression.md)。

`latest.yml` 与安装包块映射用于自动更新；`SHA256SUMS.txt` 提供本次完整发布资产的校验值。
