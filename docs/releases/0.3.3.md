# BBReader 0.3.3

## Windows 下载问题修复

此前 0.3.2 的安装器被 Windows Defender 检测为 `Trojan:Win32/Cloxer`，已撤回为草稿，不再分发。此检测尚未取得微软人工复核结论，不将其描述为已确认误报。

本版使用 GitHub 官方托管的独立环境构建，依赖按锁文件安装，并在上传产物前运行 Microsoft Defender 扫描。扫描更新病毒库，检查安装器、便携包及解包程序；失败、文件被隔离或完整性发生变化时阻止上传。扫描报告 `defender-scan.json` 记录实际病毒库版本、时间和安装包 SHA-256。

保留 0.3.2 的全部桌面、课程、下载、预览、新课件提醒及应用内更新功能，数据目录、命名与路径规则不变。

## 下载与启动

- **Windows 64 位安装版**：`BBReader-0.3.3-windows-x64-setup.exe`，推荐使用。
- **Windows 64 位便携版**：`BBReader-0.3.3-windows-x64-portable.exe`，直接启动。
- **Chrome 扩展**：`BBReader-browser.zip`，按 README 解压加载 `extension`。

请退出旧程序后安装新版。旧 0.3.1 用户需要先手动安装一次；已配置更新源的安装版可通过“连接与设置 → 软件更新”检查本仓库版本。包未配置代码签名，病毒扫描通过不等同于获得签名或永久不会被其他安全软件拦截。

`latest.yml` 和块映射用于安装版更新，`SHA256SUMS.txt` 用于完整发布资产校验。本版保留原作 Carbene/BBReader 的版权和 MIT 许可。macOS/Linux 的构建产物保存在 GitHub Actions，实机安装与签名验收仍待完成。
