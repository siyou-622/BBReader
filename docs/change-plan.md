## 2026-10-09 界面调整前的影响梳理

- 课程保存：原先只在选择有变化时允许保存；调整为相同选择也可保存，操作进行中仍防止重复提交。课程选择、后台设置及自动检查规则继续使用原实现。
- 课件行：隐藏保存路径，保留原文件入口并支持预览，增加文字下载状态、单项下载、桌面定位文件夹；批量下载、搜索、命名、目录和去重继续原规则。定位和本地预览只读取索引中的文件，不接受页面指定路径；丢失文件只标记状态，不删除历史记录。
- 时间：解析页面明确标注的上传时间；HTTP Last-Modified 只能称为文件更新时间。学校未提供时显示未知，不将下载时间或作业截止日期当作上传时间。
- 图标：使用用户提供的蓝色文档勾选图标，补充 Windows ICO、macOS ICNS、Linux PNG 和窗口图标。仅改桌面资源，不改原浏览器扩展图标。
- 回归：重复保存、失败恢复、路径隐藏、已下载/未下载/文件丢失、单项下载与定位、时间来源区分、窄屏、原批量/自动下载及打包后启动。

## 实施边界（桌面与下载）

- 新增 desktop/：Electron 主进程、安全 preload、兼容层、隐藏业务窗口；复用 extension/ 原页面与业务模块，不新增网络监听端口。
- 新增课件选择、课程全部下载、文件元数据与批次进度；服务端未给大小时显示“大小未知”，不编造。
- 下载队列持久化；重复请求拒绝，未变化文件跳过，同名保留副本，失败单项记录并可重试，重启后的中断下载反馈后可重试。
- 新增 Electron / electron-builder 开发依赖、独立打包命令与三系统 CI。最终用户无需 Node、Python 或外部浏览器。
- 扩展继续使用原 Chrome API；桌面使用同一业务队列和学校 Cookie 会话。macOS 助手安装与权限保持可选。

## 本轮修改前梳理：变更提醒与预览设置

- 扫描队列新增附件 HEAD 信息核对，新增/更新报告仅在检查完成时发布。首次收录和后续新增分别展示；升级已有索引建立版本基线；部分失败/中断不伪报“无更新”。原下载版本标记、命名和路径字段不用于写入新的检测状态，避免影响下载去重。
- 页面新增可点击的新增/更新统计及筛选、课件标记。勾选和全课程下载保留原范围；增加返回全部课件入口。
- 课件行将“原文件 · 预览”简化为“预览”，操作按钮水平排列，窄屏允许整行移到文件名下方；隐藏上传时间，保留可用的文件更新时间。
- 桌面设置增加应用内、系统默认软件、指定软件三种预览方式，默认仍为应用内；外部软件需要已下载课件。应用选择通过系统文件选择器，保存于桌面配置，不要求新安装依赖或权限。
- 回归范围：首次/新增/更新/无变化/信息缺失/中断恢复、跨课程与重复附件、报告点击筛选、课件勾选与全量范围、外部打开和设置重启保持、页面窄屏及原课程/作业/下载逻辑。

## 验证方法

先运行原 Node 回归测试，再增加选取范围、重复/非法请求、队列恢复、元数据与状态、桌面路径和权限边界测试。运行旧浏览器打包；安装桌面开发依赖后尽量运行 Windows 桌面与打包冒烟。macOS/Linux 构建由对应系统 CI 执行，学校真实账号、Keychain/Reminders 与实际登录下载需实机验收，不能以模拟测试声称已验收。

## 更新窗口修改前的清单与影响范围

- 已有安装包构建命令、NSIS/便携版、三平台 CI；尚无应用内检查更新、更新弹窗或自动安装流程。仓库远程仍为原作者 Carbene/BBReader，不能将其发布内容当成当前改造版的更新源。
- 新增独立更新模块和桌面设置/帮助菜单入口；更新状态与学校索引分离，复用 electron-updater 标准校验和安装流程。关闭自动下载、退出自动安装和降级；明确点击才下载/重启安装。
- 安装前拦截课程检查、课件下载、导出和待核对队列；不清空 Cookie、账号配置、课程索引或已下载课件。原 Chrome 扩展隐藏桌面更新界面。
- 新增生产依赖 electron-updater 6.8.9、更新源配置和发布配置脚本；CI 保存版本清单/块映射用于后续发布。默认没有发布地址、不上传任何文件。
- 回归：无更新源、开发模式、发现版本、最新版本、说明安全显示、下载失败重试/进度、重复操作、安装前阻止活动任务、退出不安装、手动包下载页，以及全部原桌面回归。
